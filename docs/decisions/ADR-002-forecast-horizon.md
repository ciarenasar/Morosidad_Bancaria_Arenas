# ADR-002: horizonte de pronóstico

- Estado: aceptada
- Fecha: 2026-08-17

## Decisión

Fijar `h = 6` meses para el MVP.

## Consecuencias

El horizonte busca equilibrar utilidad anticipatoria y cantidad de ejemplos de
entrenamiento. Los horizontes alternativos podrán tratarse como pruebas de
robustez, sin reemplazar la especificación principal.
